# Privacy Policy

_Last updated: October 10, 2026_

Crunchyroll PiP Helper adds a Picture-in-Picture control to Crunchyroll episode pages.

## Information used by the extension

To provide this feature, the extension processes information from the current Crunchyroll page locally in your browser: the page address and path, the video element's playback state, and labels on player controls. This information is used only to locate the episode player, show the PiP button, and select the video when you activate Picture-in-Picture.

The extension does not store this information, build a browsing history, or send it to the developer or other third parties. It does not use analytics, advertising, cookies, or account credentials.

## Permissions

The `scripting` permission is used when you click the extension's toolbar button to invoke Picture-in-Picture for the active Crunchyroll video. Access is restricted to Crunchyroll pages by the extension's host permissions. The extension does not execute remotely hosted code.

## Changes and contact

Changes to this policy will be published in this repository. For questions, use the support link on the extension's GitHub repository.

## Chrome Web Store Limited Use

The extension uses page information only to provide its disclosed Picture-in-Picture feature. It does not sell or transfer user data to third parties, use it for purposes unrelated to that feature, or use it to determine creditworthiness or for lending.
